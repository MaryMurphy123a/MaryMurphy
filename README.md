# Mary Murphy Personal Site

A responsive static personal site for blog posts, presentations, and profile links.

## Local preview

Open `index.html` directly, or run:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Add a blog post

1. Create a new HTML file in `posts/`.
2. Copy an existing article page for the layout.
3. Add a matching article card to `index.html`.

## Publish with GitHub Pages

Push to the `main` branch, open the repository's **Settings > Pages**, and select **Deploy from a branch** with `main` and `/ (root)`.
